# Vector-Valued Neural Networks (V-Nets)

This repository contains source code for implementing vector-valued neural networks (V-nets). V-nets are designed to process arrays of vectors while naturally considering the intercorrelation between feature channels. They often have fewer parameters and undergo more robust training than traditional real-valued neural networks, which typically learn feature intercorrelations from the data. 

### V-EfficientNets: Vector-Valued Efficiently Scaled Convolutional Neural Network Models (Example with ALL-IDB dataset)

The Jupyter Notebook "V_EfficientNetV2 - ALL_IDB2" illustrates the application of Vector-Valued EfficientNet to a medical image classification task, as described in the paper "V-EfficientNets: Vector-Valued Efficiently Scaled Convolutional Neural Network Models," which has been presented at the 2025 International Joint Conference on Neural Networks (IJCNN 2025) and is available at https://doi.org/10.1109/IJCNN64981.2025.11227779.

### Ghost Features and Spooky Transfer Learning (Example with BloodMNIST)

The Jupyter Notebook "Ghost Features and Spooky Transfer Learning (Example with BloodMNIST)" illustrates the extraction of Ghost Features and the concept of Spooky Transfer Learning, as described in the paper "Ghost Features and Spooky Transfer Learning for Hypercomplex-Valued Neural Networks," which has been accepted for presentation at the 2026 IEEE International Workshop on Machine Learning for Signal Processing (MLSP 2026).
